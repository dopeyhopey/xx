<VSCode.Cell language="markdown">
## 💡 The big idea

Git helps you keep track of your work over time.

Think of it like a save history for your project:

- **commit** = a saved checkpoint
- **push** = upload your checkpoints to GitHub
- **pull** = download updates from GitHub
- **repository** = your project folder with history

You are not just saving files.  
You are saving versions of your project.

</VSCode.Cell>

<VSCode.Cell language="markdown">
## 🧠 Easy definitions

- **commit** = local save
- **push** = upload to GitHub
- **repository** = the main project folder with history
- **pull** = download changes onto your computer
- **refactor** = improve or clean up work without changing the main idea
- **bash** = the command shell used to run Git commands

A repository is like a project brain with memory.  
It keeps track of what changed and when.

</VSCode.Cell>

<VSCode.Cell language="markdown">
## 🪄 The basic workflow

This is the beginner flow:

1. Check what changed
2. Pick the files to save
3. Make a commit
4. Push to GitHub

That’s it.  
You do not need to be a coder to use this.

</VSCode.Cell>

<VSCode.Cell language="bash">
git status
git add .
git commit -m "Add summer collection notes"
git push
</VSCode.Cell>

<VSCode.Cell language="markdown">
## 📌 What each command means

- **git status** = shows what changed
- **git add .** = selects files to save
- **git commit -m "..."** = saves a checkpoint
- **git push** = uploads your saved work to GitHub

### Tiny memory trick:
- **status** = what changed
- **add** = choose files
- **commit** = save checkpoint
- **push** = upload

</VSCode.Cell>

Git is basically your project backup + timeline + brain map.

It helps you:
- save your work
- avoid losing progress
- keep versions
- stay organized
- remember what you did

You are not “doing code.”  
You are organizing your creative work in a smarter way.
